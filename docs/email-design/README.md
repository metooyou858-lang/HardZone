# Макеты писем соревнований

Рабочие макеты для согласования, 11.09.2026. Это отдельные HTML-письма, не подключённые к событиям регистрации или очереди отправки.

На основе этой серии подключлены production-шаблоны `backend/src/assets/competition-email-templates.json`: реальные данные и персональные ссылки подставляет `competition-email.js`. Статические файлы в этой папке остаются демонстрационными. Контракт отправки описан в `docs/COMPETITION_AUTOMATION.md`.

Подтверждено владельцем: оформление наследует страницу регистрации соревнований. Использованы её исходная афиша, бумажный фон `#f0ede4`, текст `#121412`, вторичный текст `#686960` и основное действие `#c4c33a` — приглушённый жёлтый на основе надписи CHALLENGE. Бирюзовый исключён по уточнению владельца 11.09.2026. Для почты шрифты заменены системными; основной контент остаётся текстом, а не картинкой.

Серия: заявка принята, напоминание через 45 минут, отмена по истечении 60 минут и подтверждение оплаты. Срок показан абсолютной датой и временем Хабаровска. Пример команды и срока демонстрационный. Все платёжные кнопки макетов ведут на публичную страницу соревнований и не инициируют платёж. Настоящие персональные URL и чаты должны подставляться при реализации.

Уточнение владельца: чаты общие для всех категорий. В письме об оплате две действующие кнопки: [WhatsApp](https://chat.whatsapp.com/CmIOwJVasUwCTiRQXS23py?s=cl&p=a&mlu=4&ilr=4) и [Telegram](https://t.me/games_khv). Категория остаётся только характеристикой команды. Обязательность резервирования места не заявляется: правило и лимиты пока не согласованы.

Версия 2: моноширинные «печатные» шрифты исключены из HTML-текста, включая блок даты под афишей и подписи. Заголовки и эти блоки используют Segoe UI / Helvetica / Arial. Растровая исходная афиша не изменена.

`node docs/email-design/build.cjs` собирает четыре HTML-файла и `messages.json`. Для CID-вложения брать `bannerFilename` из сообщения: `competition-banner-email.jpg` рядом с HTML. При отправке заменять относительный src на CID.

Оптимизация загрузки: исходный PNG 3000 × 1688 весил 3 511 268 байт. Для писем сохранён JPEG 1280 × 720, качество 82, mozjpeg, 80 327 байт (меньше в 43,7 раза). Ширина письма 640 px, поэтому остаётся двойная плотность изображения. Сохранённый JPEG визуально проверен отдельно; исходная афиша сайта не менялась. Не вкладывать исходный PNG при последующих отправках.

Статус проверки: выполнена проверка исходных материалов и структуры. Визуальная приёмка не выполнена: локальный file URL заблокирован браузером, установка отдельного рендерера отклонена автоматической проверкой. Макеты отправляются владельцу для просмотра в Gmail; не считать их визуально принятыми или готовыми для автоматической рассылки до проверки.
