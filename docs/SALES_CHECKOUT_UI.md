# Компактная касса

Согласовано 23.09.2026: на ноутбуках каталог и текущий чек стоят рядом. Высоту рабочей области задаёт оставшееся место в AppShell, а не фиксированный вычет из viewport: заголовок и уведомления могут переноситься. Список позиций и каталог прокручиваются независимо; итог и оплата находятся вне списка.

Позиция показывает название, сумму, количество, цену и удаление. Скидка раскрывается по запросу. Поле маркировки после ввода сворачивается с возможностью изменить код; «Код введён» не означает проверку или сохранение в кассе.

Проверено на production с четырьмя маркированными позициями при фактических CSS viewport 994×621 и 1243×699: высота main равна scrollHeight, список имеет собственное переполнение, кнопки оплаты внутри экрана. Проверочные оплаты не отправлялись.

При деплое этой правки Turbopack повторно использовал CSS без новых utility-классов, даже после touch globals.css. Перенос `.next/cache` из каталога сборки и полная сборка восстановили стили. Успешный next build сам по себе не подтверждает применение компоновки: проверять computed styles на домене.
