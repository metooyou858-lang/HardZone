# Визуальное направление публичной страницы соревнований

Статус: рабочее направление, утверждено владельцем как отказ от шаблонного «AI-дизайна».

- Платформа: публичная адаптивная web-страница HardZone.
- Режим: consumer transactional с выразительной клубной афишей.
- Главная задача: понять формат М + Ж и отправить одну заявку на команду.
- Характер: industrial как основа, editorial как вторичное влияние.
- Композиция: единый последовательный экран без постоянной боковой колонки — клубная афиша открывает страницу, затем в одном светлом потоке идут условия и заявка команды.
- Типографика: локально размещённый кириллический Alumni Sans для афиши и главных заголовков; нейтральный интерфейсный sans-serif для формы, IBM Plex Mono для даты и служебных меток. Узкое спортивное начертание используется дозированно, а не на всём экране.
- Цвет: чёрный и тёплый светлый фон; фирменный `#5EF4D8` используется только для акцента и основного действия.
- Геометрия: прямые линии, минимальные радиусы, без набора взаимозаменяемых карточек, градиентов и декоративных бейджей.
- Сетка: данные на афише, условия проведения и форма используют одну центральную колонку шириной до 900 px и совпадающие боковые границы.
- Изображения: афиша является единым фоном первого экрана; информация о событии накладывается поверх нижней затемнённой зоны. На desktop используется горизонтальный исходник 3000 × 1688 с `cover`. На телефонах до 640 px вертикальный исходник 2400 × 3000 показывается целиком по ширине через `background-size: 100% auto`, без обрезания текста афиши; оставшаяся нижняя зона продолжается чёрным фоном.
- Афиша: композиция публичной страницы экспортируется отдельным PNG 1080 × 1350 с датой, форматом, категориями, взносом и адресом.
- Адаптив: единый вертикальный поток на desktop и мобильных экранах; минимум 320 px без горизонтального скролла.
- Состояния: загрузка, закрытая регистрация, ошибка и успешная заявка сохраняются.
- Подробные ограничения категорий раскрываются по запросу внутри страницы, чтобы длинный текст не отодвигал форму без необходимости.
- Согласие с условиями мероприятия и согласие на обработку персональных данных являются двумя отдельными действиями.
