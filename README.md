# HardZone

Monorepo проекта HardZone с фронтендом и backend API.

## Структура

- `frontend/` — Next.js интерфейс CRM/склада
- `backend/` — Express + PostgreSQL API

## Запуск локально

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run start
```

## Важно

Секреты и рабочие `.env` файлы в репозиторий не включены.
